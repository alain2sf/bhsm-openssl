OpenSSL & BouncyHSM v2.3.1 integration demo.

This project provides a practical, step-by-step runbook for integrating and configuring an OpenSSL & BouncyHSM v2.3.1 prototype within an Ubuntu 26.04 LTS virtual machine managed by Multipass on macOS Tahoe 26 (ARM64).
